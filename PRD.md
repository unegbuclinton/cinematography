You are an expert creative director, award-winning digital product designer, UX designer, interaction designer, and senior frontend engineer.

Your task is to design and build a **world-class portfolio website for a professional videographer / filmmaker**.

This should not feel like a generic agency template, a SaaS landing page, or a standard grid of projects.

The website itself should feel like an extension of the videographer's creative work.

The goal is to create an experience that is:

- Cinematic
- Premium
- Minimal
- Highly visual
- Emotionally engaging
- Extremely intuitive
- Fast and technically polished
- Focused on showcasing video work without overwhelming the visitor

## Core Principle

The work is the product.

The interface should never compete with the videos. Everything should exist to help visitors discover, experience, understand, and remember the videographer's work.

Think carefully about the actual user journey.

A visitor may be:

- A potential client
- A creative director
- A brand
- A production agency
- A collaborator
- A fan of the filmmaker's work

Within seconds, they should understand:

1. Who this person is
2. What kind of work they create
3. How good the work is
4. What their creative style is
5. What types of projects they work on
6. How to explore more work
7. How to contact or hire them

## First: Research and Planning

Before writing the final UI, analyze the project and create a strong visual and UX direction.

Do not immediately build a generic portfolio.

Think like a creative director.

Study the conventions and interaction patterns used by exceptional portfolios from:

- Cinematographers
- Directors
- Filmmakers
- Photographers
- Creative studios
- High-end fashion and editorial websites

Take inspiration from modern editorial design, cinema, architecture, fashion, and premium creative portfolios.

However:

**Do not copy any specific website.**

Create an original design system and interaction language.

---

# UX Philosophy

The user experience should be built around one central idea:

> Browsing the portfolio should feel effortless, almost like discovering a beautifully curated film collection.

Avoid making the user work.

Do not overload the screen with:

- Excessive menus
- Too much text
- Too many labels
- Multiple competing calls to action
- Unnecessary animations
- Heavy UI cards
- Generic buttons everywhere
- Over-designed interface elements

The interface should be calm.

The visitor should always understand:

- Where they are
- What they are looking at
- What they can do next

Navigation should feel almost invisible but always accessible.

---

# Homepage Experience

The homepage should immediately establish the videographer's identity and quality.

The hero section should be visually powerful and may feature:

- A showreel
- A cinematic background video
- A carefully selected featured project
- A bold visual composition with minimal typography

The hero should not feel like a standard marketing banner.

Think about:

- What is visible before scrolling
- How quickly the visual content begins communicating
- Whether video should autoplay silently
- How playback is controlled
- How the site behaves on slower connections

The user should never feel trapped inside an autoplaying video.

Provide subtle and intuitive controls where necessary.

The homepage should flow naturally into the work.

For example:

1. Strong opening visual statement
2. Selected or featured work
3. A carefully curated project experience
4. Short personal or creative statement
5. Selected clients / recognition where appropriate
6. Clear but elegant path to contact

Do not force every traditional portfolio section onto the homepage.

Prioritize quality over quantity.

---

# Project and Video Display

This is one of the most important parts of the website.

Most of the portfolio content will consist of video projects.

Design an excellent system for displaying projects.

Each project should have:

- Strong visual thumbnail or poster frame
- Project title
- Optional client / category / year
- Clear indication that it can be explored or played

Avoid traditional cluttered card designs.

Projects should feel like editorial pieces or works in a curated collection.

Consider layouts such as:

- Full-width visual projects
- Editorial grids
- Large and small visual rhythm
- Horizontal or vertical project exploration
- Carefully curated asymmetry

However, responsiveness and usability are more important than being visually unusual.

## Video Interaction

Think deeply about the video experience.

Questions to solve:

- Should videos preview on hover?
- How should previews behave on touch devices?
- When should full videos load?
- Should clicking a project open a dedicated project page or immersive player?
- How does the visitor easily return to browsing?
- How should playback state be handled?
- How do we avoid multiple videos competing for attention?

Hover previews should feel premium and useful, not distracting.

Do not autoplay every video simultaneously.

Only the appropriate video should become active based on the user's interaction.

If hover previews are used:

- Start subtly
- Use muted playback
- Avoid aggressive looping behavior
- Stop unnecessary videos when they leave focus
- Gracefully fall back to poster images when needed

Video playback must be:

- Fast
- Reliable
- Accessible
- Mobile-friendly

The design should prioritize performance.

---

# Project Detail Pages

Project pages should feel immersive.

A project page should tell the story of the work without becoming a long, unnecessary case study.

Possible structure:

### Project Header

- Project title
- Client
- Category
- Year
- Optional role / credits

### Main Video

The video should receive the visual priority.

### Project Context

A concise description explaining the project.

Do not create large walls of text.

### Supporting Content

Where appropriate:

- Behind-the-scenes imagery
- Stills
- Credits
- Production details
- Creative process
- Related projects

At the end of the project, create a natural transition into another project rather than simply stopping the experience.

The visitor should feel encouraged to continue exploring.

---

# Navigation

Navigation should be minimal and extremely clear.

Potential structure:

- Work
- About
- Contact

Or another equally simple structure if it better supports the final experience.

Do not create navigation complexity just because more pages exist.

The navigation should remain easy to access without becoming visually intrusive.

Consider:

- A minimal fixed navigation
- Intelligent contrast depending on the background
- A subtle menu for secondary navigation
- Clear active states

The mobile navigation must receive the same level of attention as desktop.

Do not simply shrink the desktop navigation.

---

# About / Bio Experience

The biography should feel personal and human.

Avoid the typical corporate "About Me" page.

The visitor should quickly understand:

- Who the videographer is
- Their creative perspective
- Their area of focus
- Their experience
- Their working style

Use strong typography and visual composition.

Potential content:

- Portrait or studio image
- Short personal statement
- Longer biography if necessary
- Selected clients
- Awards or recognition
- Services
- Location / availability
- Social links

The typography should carry personality.

Do not make the page text-heavy.

---

# Typography

Typography is a major part of the experience.

Create a strong typographic system.

The typography should feel:

- Editorial
- Confident
- Modern
- Premium
- Timeless

Use contrast between display typography and functional body typography where appropriate.

Typography should create hierarchy without relying on excessive UI elements.

Pay close attention to:

- Scale
- Spacing
- Line height
- Text width
- Mobile readability
- Hierarchy
- Alignment

Large typography can be used confidently, but it must not compromise usability.

Avoid generic oversized text simply because it is a design trend.

Every typographic decision should support the content.

---

# Animation and Motion

Motion should feel intentional, refined, and cinematic.

Do not add animation just to make the website look impressive.

Every animation should have a purpose.

The site should feel smooth and alive, but never busy.

Possible motion principles:

### Page Transitions

Use subtle transitions that create continuity between pages.

Avoid slow transitions that make navigation feel delayed.

### Project Interactions

Project hover states should provide useful feedback.

Consider subtle changes such as:

- Video preview
- Image movement
- Text transitions
- Mask reveals
- Scale changes

These should be restrained.

### Scroll Animations

Use scroll motion sparingly.

Avoid the common pattern where every element dramatically fades upward.

Instead, create a few distinctive motion moments.

### Micro-interactions

Buttons, menus, cursor states, playback controls, and navigation should have polished feedback.

Motion should feel:

- Smooth
- Responsive
- Intentional
- Fast

Always respect:

`prefers-reduced-motion`

The website must remain fully usable with reduced motion.

---

# Visual Design

Create a refined visual system.

Avoid:

- Excessive gradients
- Glassmorphism unless genuinely justified
- Heavy shadows
- Rounded cards everywhere
- Generic UI components
- Excessive borders
- Dashboard-style layouts
- Template-like design

The visual design should support photography and video.

Think carefully about:

- Negative space
- Visual rhythm
- Image ratios
- Contrast
- Background colors
- Text overlays
- Full-screen moments

The interface should know when to disappear.

The portfolio content should dominate.

---

# Responsive Design

This is not a desktop website that has been compressed for mobile.

Mobile is a first-class experience.

Consider how a visitor naturally interacts with a videographer's portfolio on:

- Large desktop screens
- Laptops
- Tablets
- Mobile devices

On mobile:

- Videos should remain easy to play
- Project discovery should remain intuitive
- Typography should remain impactful but readable
- Navigation should be simple
- Touch interactions should replace hover assumptions

Do not hide important content simply because the screen is smaller.

Redesign interactions where necessary.

---

# Performance

Performance is essential.

A beautiful video portfolio that takes too long to load is a bad user experience.

Optimize for:

- Fast initial page load
- Progressive media loading
- Poster images
- Lazy loading
- Video optimization
- Responsive media sizes
- Avoiding unnecessary JavaScript
- Smooth animations

Do not load every project video immediately.

Prioritize the content currently visible to the user.

Create a clear media-loading strategy.

---

# Accessibility

The website should remain highly usable for everyone.

Consider:

- Keyboard navigation
- Focus states
- Semantic HTML
- Screen readers
- Color contrast
- Video controls
- Reduced motion preferences
- Mobile accessibility

Premium design and accessibility are not competing goals.

Both should be excellent.

---

# Design System

Build a consistent but flexible design system.

Define:

- Typography scale
- Spacing system
- Layout grid
- Navigation behavior
- Button and link interactions
- Media behavior
- Animation principles
- Breakpoints

Do not over-componentize purely for abstraction.

Create reusable components where repetition genuinely exists.

---

# Build Quality

The final implementation should be production quality.

Requirements:

- Clean architecture
- Reusable components
- Responsive
- Accessible
- Performant
- No placeholder-feeling UI
- No generic template sections
- No unnecessary dependencies
- Clean animations
- Proper loading states
- Proper error states for media where needed

Do not stop after creating the basic layout.

Iterate on the design.

Review the result as if you are a creative director reviewing a portfolio for a premium filmmaker.

Ask:

- Does this feel distinctive?
- Is the work the focus?
- Is anything visually distracting?
- Is the navigation obvious?
- Is the project browsing experience intuitive?
- Are animations improving the experience?
- Is the mobile experience genuinely good?
- Does it feel expensive without being over-designed?

If something feels generic, refine it.

If something is visually impressive but hurts usability, simplify it.

## Final Goal

Create a portfolio that feels like the work of an exceptional filmmaker is being presented through an exceptional digital experience.

The visitor should leave thinking:

> "This person clearly cares about craft."

The final website should be cinematic and memorable, but above all:

**clear, fast, intuitive, elegant, and effortless to explore.**
